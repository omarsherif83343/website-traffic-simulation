# Website Traffic Simulation

Python project that simulates website traffic using NumPy and visualizes visitor behavior with Matplotlib. The project generates synthetic website activity data and analyzes visitor patterns, user registration rates, and session duration distributions.

## Tools Used

* Python
* NumPy
* Pandas
* Matplotlib

## Project Objectives

* Simulate website visitors per hour
* Analyze traffic patterns
* Generate visitor statistics
* Simulate registered user activity
* Visualize traffic behavior

## Key Performance Indicators (KPIs)

* Maximum Visitors per Hour
* Minimum Visitors per Hour
* Average Visitors per Hour
* Registered Users per Hour
* Visitor Stay Time Analysis

## Features

* Website traffic simulation using Poisson distribution
* Registered user simulation using Binomial distribution
* Stay time simulation using Normal distribution
* Traffic data reshaping and filtering
* Statistical analysis of visitor activity

## Visualizations

* Visitors Per Hour Distribution
* Stay Time Distribution
